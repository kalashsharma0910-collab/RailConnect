# 🚆 RailConnect | Railway Booking System

RailConnect is a railway booking web application built with React that allows users to search trains, view train information, calculate fares, and manage simulated bookings through an intuitive interface.

The application uses publicly available railway data to demonstrate how an online reservation system works. It is a portfolio project intended for learning and showcasing frontend development skills.

> **Note:** RailConnect is not an official railway reservation service. Bookings, seat availability, and confirmations are simulated for demonstration purposes only.

---

## ✨ Features

- Search trains by source and destination stations
- View train details, schedules, and travel classes
- Enter passenger information through booking forms
- Automatic fare calculation based on selected options
- Generate booking references for demo reservations
- View and manage saved bookings
- Responsive design for desktop and mobile devices
- LocalStorage integration for data persistence

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
# Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL

# Navigate to the project directory
cd RailConnect

# Install dependencies
npm install

# Start development server
npm run dev
```

Open the URL displayed in the terminal to access the application.
